# bulbaShell
bulbaShell - простая ОС написаная на c#, использует COSMOS

# как использовать
1) скачайте и .net (5 версии) cosmos User kit: 
https://github.com/CosmosOS/Cosmos/releases,
https://dotnet.microsoft.com/ru-ru/download/dotnet/5.0.

2) скачайте VS 2019, сделайте файл (с cosmos) и замените "karnel.cs" на который в репе
3) билдите, добавляйте свои функции и используйте! ;3
